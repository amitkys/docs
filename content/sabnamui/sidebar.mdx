## Features

- **Collapsible Layout**: Toggle between expanded (280px) and collapsed (90px) modes with smooth CSS transitions.
- **Nested Submenus**: Accordion-style collapsible submenus when expanded, converted automatically to hover dropdown menus when collapsed.
- **Persistent State**: State automatically preserved in `localStorage` using `zustand` middleware.
- **Tooltip Integration**: Icon tooltips shown on hover when sidebar is collapsed.
